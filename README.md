# M²BC — Use-Case-Dossier

One-Pager für M² Business Consulting GmbH: drei Fälle aus dem industriellen
Mittelstand, aufbereitet als Case-Study-Dossier.

Struktur-V1 — reines Fundament (14 Sections, vollständiger Content,
Design-System), noch ohne visuelle Effekte. Diese kommen iterativ dazu
(Parallax, GLSL-Shader, CD-Anpassungen).

## Stack

Vite + React + TypeScript + Tailwind CSS.

## Entwicklung

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
